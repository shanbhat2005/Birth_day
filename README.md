# ✨ Interactive Birthday Celebration Web Experience 🎂🎉

A modern, immersive, and festive birthday celebration web app built with React, Vite, Canvas-Confetti, and Web Audio API synthesis.

## 🌟 Key Features

- 🎁 **Interactive 3D Gift Box Unboxing**: Suspenseful unboxing animation with sound effects and custom confetti cannons.
- 🎈 **Interactive Floating Balloons**: Pop balloons on click with custom sound effects and localized particle bursts.
- 🎂 **Interactive Birthday Cake**: Blow candles with audio simulation, realistic smoke animation, and relighting capability.
- 💌 **Wax-Sealed Unfolding Letter**: Custom wax seal break animation, personalized message with live inline editing.
- 🎵 **Synthesized Birthday Melodies**: Custom Web Audio API synthesizer for background music and festive sound effects without external audio assets.
- ✏️ **Dynamic Name Customization**: Easily personalize the birthday person's name dynamically.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or newer recommended)
- npm

### Installation & Development
```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run linter
npm run lint
```

## 🛠️ Tech Stack
- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Visual FX**: [canvas-confetti](https://www.npmjs.com/package/canvas-confetti)
- **Audio FX**: Web Audio API (Synthesized)
- **Linter**: [Oxlint](https://oxc.rs/)
